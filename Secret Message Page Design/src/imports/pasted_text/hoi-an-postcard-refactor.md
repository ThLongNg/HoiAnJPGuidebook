Refine the current Secret Message page into a much more personal and emotionally meaningful experience.

The current design is visually beautiful, but it feels slightly too generic and template-like. It should feel less like a “premium secret message feature” and more like a small personal travel postcard that I created specifically because the recipient is visiting Hoi An.

IMPORTANT:
Do not make it romantic or overly sentimental.
Do not use hearts, romantic symbols, couple imagery, or love-letter aesthetics.
The emotional tone should be:
warm, sincere, personal, thoughtful, slightly nostalgic, and memorable.

The page should communicate:
“I remembered that you are going to Hoi An, so I made this little thing for you.”
